# Server Health Monitor

## Project Description

Server Health Monitor is a Python-based automation project that collects important system health information from a Linux server.

The project demonstrates Python scripting, Linux system administration, Git version control, and GitHub repository management.

## Features

The script automatically collects and displays:

- Hostname
- Current logged-in user
- Current date and time
- Operating system
- Kernel version
- CPU usage
- Memory usage
- Disk usage
- Primary IPv4 address
- System uptime

The script also automatically generates a server health report.

## Technologies Used

- Python 3
- Linux / Ubuntu
- psutil
- Git
- GitHub
